## p130

Biofeedback scanning, GeneratorX Pro specifics. Mostly GUI, but three hard numbers and one
named preset set that belong in a recommendation engine:

- **STATED:** TENS pads "should be as close together as possible, **with the pathogens
  between the two pads**" (GX Pro scanning). *INFERENCE for the tool: pathogen contact
  material is placed between the pads, not on them.*
- **STATED:** ticking **`Baseline Before BFB`** *doubles* the scan time of
  `GX Fast Biofeedback Scan (C) - JW` and *increases by 50%* the scan time of
  `GX General Biofeedback Scan (C) - JW`.
- **STATED:** `GX General Biofeedback Scan with Baseline (C) - JW` "includes a baseline, and
  because it only does one loop, it takes the same time as" the non-baseline General scan.
- **STATED:** "**If a scan is interrupted, you must restart it from scratch. Scans cannot be
  paused once they've started.**" (Operational limit, not a recommendation input.)
- Screenshot buttons visible and not explained elsewhere: `Scan`, `Analyze`, `Analyze +`,
  `Baseline`, and the `Baseline Before BFB` checkbox. A `Stop` button is referenced in prose
  but is not in the cropped screenshot on this page.
- **New biofeedback operating modes (names matter if the tool ever surfaces a scan-driven
  program):** **Scan and Run** — "perform a scan, then treat immediately (without creating a
  preset), scan, treat, scan, treat"; and **Hunt and Kill** — "each subsequent scan is a
  refinement of the previous scan". Optional `Run on Gen` lets treatment run on a *second*

  scans (scan only or Hunt-and-Kill).

## p142

**§10 Frequency Conversions — the single most decision-relevant page in this batch for the
22,985 DNA presets.**

- **STATED scope:** "These advanced controls affect the **Molecular Weight and DNA programs
  only** — they have **no effect on the Main database programs**. Best left to experts."
  > **TOOL RULE: editing the conversion factors silently changes the meaning of every MW and
  > DNA program and every DNA preset. DNA/MW presets are only comparable to each other under
  > one factor set. Never normalise DNA preset frequencies without recording the factor set
  > in effect.**
- **STATED mechanism:** "The MW database contains the molecular weight of many different
  compounds, elements, and important molecules. **These molecular weights can be converted
  to frequencies using a mathematical formula.** This formula incorporates several physics
  constants, **one of which is the speed of light in a vacuum**. Some authorities believe
  that the speed of electromagnetic energy in tissue is more suitable, so **the fields here
  are editable.**"
- **Field definitions (STATED, verbatim meanings):**
  - `MW to Hz Factor` — "the calculated result when the **Molecular Weight is 1**."
  - `MW Inhibit Factor` — "**apply this factor to MW frequencies to inhibit the harmful
    effects of the molecule.**" Cross-reference: `Apply Inhibit Factor to Harmful
    Substances` in the `Options` pane.
    > This **confirms what the √2 constant is for** (KNOWLEDGE §3.1 had it only as a
    > corpus value). It does **not** yet explain the `MW Emulate` vs `MW Remove` shell
    > split — but it establishes that an **inhibit** operation is a first-class software
    > transformation, so a shell named "Remove X" plausibly means *apply MW Inhibit to
    > substance X*. Still INFERENCE, still unconfirmed.
  - `DNA to Hz Factor` — "the calculated result when the number of **DNA base pairs is 1**."
  - `RNA to Hz Factor` — same for **RNA base pairs = 1**.
  - `mRNA to Hz Factor` — same for **mRNA base pairs = 1**.
  - `Restore Frequency Conversion Defaults` — "restore these **5 values** to their factory
    defaults." → **exactly five conversion factors exist.**
- **Worked example given in the screenshot (STATED values):**
  `MW to Hz 2.2523430883E+23` · `MW Inhibit 1.4142135623730950480816887242` ·
  `DNA to Hz 3.06735269246603E+17` · `RNA to Hz 3.74222102678858E+17` ·
  `mRNA to Hz 3.74222102678858E+17`.
  > **INFERENCE, and this is the useful one:** a DNA program of *n* base pairs yields
