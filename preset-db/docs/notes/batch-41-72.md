## p050 / p054 / p067 — **Reverse Lookup: how the software decides which program to run**

This is the single most important mechanism in the batch for a recommender tool.

**The Reverse Lookup panel** (visible in the Generator Control Panel screenshots on p50, p54, p67):

| Control | Meaning |
|---|---|
| `Include Harmonics` | checkbox — also match N×k of each found frequency |
| `Include Sub-Harmonics` | checkbox — also match N÷k |
| `Octave` (dropdown) | tolerance expressed in octaves |
| `.05` `% Tolerance` | numeric tolerance; p59/p62 show `.0125` |
| `Include 14343` `Hz In Search` | inject a specific frequency into the search set (14343 Hz is the value shown) |
| `Go` | run the lookup |

**What it does, verbatim (p59 and p62, identical wording in both):**
> "the *Reverse Lookup* results, which are **programs in the database that may match your found
> frequencies**"

So: **biofeedback finds frequencies → Reverse Lookup returns database programs whose
frequencies fall inside a tolerance window around those found frequencies.** It is a
frequency-set-to-program match, not a name match and not a diagnosis.

**The `Octave` dropdown matters because the same pathogen appears at different octaves.**
p60 shows every Salmonella hit annotated `(Octave #3)`; p62 shows `Arithrophospholipid
Syndrome (Octave #1)`, `Stuttering (Octave #3)`. A program at octave *k* matches a scan hit
at octave *j*; `Include Octaves` / `Include Sub Octaves` control whether the match is widened
across octaves. **Practical consequence: the recommender must be octave-aware.**

**The `Reverse Lookup Results` window (p60/p62), text quoted from the screenshot:**

> "PLEASE NOTE: This is **NOT a diagnostic tool**. Many health issues share the same frequencies.
> **Reverse lookup does NOT mean you have these illnesses.**"

> "Databases included in search: ALT, BFB, BIO, CAFL, CUST, ETDFPL, HC, KHZ, PROV, RIFE, VEGA, XTRA"
> "Databases excluded in search: BP, DNA, MW"

Matching is reported **per hit frequency, with an explicit tolerance band**:
- p60: `Matches found for 41,123 Hz: (41,117 Hz - 41,128 Hz)` →
  `Salmonella Enteridis Gut (Octave #3), Salmonella Enteriditis (Octave #3),
  Salmonella Infections (Octave #3), Salmonella Paratyphi (Octave #3)`;
  then `No matches found for 59,363 Hz`; then `Matches found for 62,200 Hz: (62,192 Hz - 62,207 Hz)`.
- p62: `Matches found for 124,686 Hz: (123,439 Hz - 125,932 Hz)` →
  `Arithrophospholipid Syndrome (Octave #1), Stuttering (Octave #3), Ulcerative Colitis,
  Paresthesias Anosotoma caninum, Keratitis Ulcerative`.

**→ Two things a recommender must reproduce: (a) hits with no match are normal and must not
be forced into a program; (b) one hit legitimately maps to many unrelated programs, because
frequencies are not unique to one organism.**

**Carrier construction (p65–p67):** "A **dynamic carrier** is always better because it's
automatically a higher harmonic of each audio frequency." Two methods exist: the **"Out 2"
method** and the **"F2" method**. In the F2 method set **`Out 2 = (Out 1 X 1) + 0`** (i.e.
*Inverse*, not *Follow Out 1*) and use `F2 = F1  128  Hz`.
- **Why 128:** "once audio energy reaches the top of the range of human hearing (about
  20,000 Hz) it's becoming radio energy. By trial and error, we find that multiplying our
  audio frequencies by 128 transposes all of them to radio frequencies. **We pick 128 because
  it's an octave multiplier**, and octaves can be clearly seen in many aspects of life,
  creation, and the universe."
- **Octave multipliers/divisors:** 2, 4, 8, 16, 32, 64, 128, 256, 512. "There are other
  excellent types of multiplier — **decade, Fibonacci, and 8x (particularly powerful)** — but
  we'll almost always have good results with octaves."
- **WCM = headroom, not a requirement:** set square-wave `WCM` to 4 to allow later higher
  frequencies → "a max ceiling of 20 MHz" (default 1 → 5 MHz). Worked example (p67):
  47 Hz × 128 = **6,016 Hz** carrier; 10,000 Hz × 128 = **1,128,000 Hz**, "well within the
  generator's native hardware limit of 5,000,000 Hz."
- **Contact mode polarity:** enter **60 seconds** as `Swap Waveform` time to prevent acids
  forming under the TENS pads and burning skin. Set `Amplitude` for Out 1 and Out 2 to **20**.
  Use `Ramp Up`/`Ramp Down` of 5 V/sec + `Reduce Amplitude` rather than risking a sting.

## p071 / p072 — `Create Program`: the custom database, and the program mini-language

Verbatim (p71): "Spooky² allows you to enter **an unlimited number of your own programs into a
custom database**. The `Create Program` screen contains complete instructions, and **saves your
work into `custom.csv`**."

**`Create Program` window fields (p71):** `Program Name` · `Frequencies` · `Dwell` (default **180**)
· `Program Description`. (The scan-generated version, p60, additionally shows
`Email a copy to Cancer Clinic NZ` and a pre-filled "Program Created …" description.)

**The instruction block, transcribed from the screenshot (this is the program syntax the
tool must understand):**

```
Frequencies (and optional advanced commands) are entered using a comma to separate each program step.
xxx-yyy   Sweeps the frequency from xxx Hz to yyy Hz.
          Example: 2127=180,2128=240,2127-2128=600
=xxx      x is the dwell (seconds) this frequency is to be applied. Example: 2127=180,2128=240,2127-2128=600
W x       x is the waveform for this frequency. W sets Out 1 and w sets Out 2.
1 Sine · 2 Square · 3 Sawtooth · 4 Inverted Sawtooth · 5 Triangle · 6 Damped Sinusoidal ·
7 Damped Square · 8 H-Bomb Sinusoidal · 9 H-Bomb Square · 10 User Defined #1 · 11 User Defined #2
Gx:       x is 1 to turn gating on, 0 for no gating.
Ax:       x is the amplitude (voltage peak to peak) of Out 1.
```

> **Note the sweep example: `2127-2128=600` is a 1 Hz-wide band swept for 600 seconds.**
> That is a *narrow, targeted* sweep — a different animal from a full spectrum sweep. **The
> recommender must not treat every `xxx-yyy` in a frequency list as a full sweep.**

**Semantics of the other three fields (p72):**
- `Program Name` — "Give it a good descriptive one so you'll be able to identify it in a search
  list. Something like **"Cancer Throat Sweep YI"** is good because it will show in searches for
  "cancer," "throat," and "sweep." You can substitute YI with your initials, a numeral, or leave
  it out entirely."
  → **Program names are the search index. Words in a name are the tags a user searches by.**
- `Frequencies` — "each frequency in the set **must** be separated by a comma."
- `Dwell` — "the amount of time in seconds you wish to transmit each frequency in your Program
  for. If you're unsure of what this should be, **180 seconds is a good default.**" Individual
  deviations use the `=xxx` command.
- `Program Description` — "Any notes for this program should be entered here. **Spooky2 will
  include this in searches.**" Editable later via **`Edit Custom Database`** in the
  **`Database` menu**, or by opening `custom.csv` in Notepad.

> **→ The program-name + description pair is the full-text search index across all databases.
> The recommender's matching should therefore search *both* fields, exactly as the software does,
> and `custom.csv` is a user-writable database that participates in the same search.**

## §Reading the corpus's filename grammar (pages 41–58 add the rules explicitly)

  (JW, JK, MM, DH, MA, BY, EV, JD) — different initials = different settings, not synonyms.
- Saved as `Text (*.txt)`, i.e. **one plain-text file per preset**, filed under
