## p029

**Settings tab — and a hard restriction on presets.**

- "If you load a preset first, then click in here, you'll see the settings **already programmed
  for you**. While you're free to change these as you wish, we **strongly recommend that you don't
  alter any Spooky Central/Plasma presets unless you know exactly what you're doing**. However,
  you're **always free to alter settings in the *Schedule* and *Audio Options* panes**."
  → **Two-tier rule: (1) never hand-edit a Central/Plasma preset's signal settings;
  (2) Schedule and Audio Options are universally safe to override.**
  → *INFERENCE: a shell preset for Plasma is a *protected* preset — the recommender should emit
  Plasma shells as "load as-is, do not modify" and Schedule overrides as the only sanctioned
  edit.*

**Legible pane inventory (signal semantics a preset controls):**
- **Signal Settings** — `Duty Cycle` 50% / 50% `%`; `Amplitude` 5 V / 5 V; `Offset` 0% / 0%;
  `Phase` 0° / 0°; a **`Modulate Out 1` checkbox with a padlock icon**; `Restore Defaults`.
  → *Note the `50%` duty defaults — consistent with the p7 rule "never use a duty value other
  than 50% with Spooky Central/Plasma".*
- **Gating** — `4 Hz Gate` / `125 mS On` / `125 mS Off`; per-output `Out 1` / `Out 2` enables.
  → **A shell preset can hard-gate the output on/off at 4 Hz with 125 ms on / 125 ms off. This is
  one of the few things that genuinely differs between otherwise-similar shells.**
- **Wobble** — `Amplitude Wobble` (Disabled, %, Steps=16) · `Frequency Wobble` (Disabled, %, Steps=16) ·
  `Harmonic Wobble` (None).
- **Schedule** — `Run From` Midnight `to` Midnight; `Start In` 0 Days / 0 Hours / 0 Minutes;
  `After … 0 Hours`; radio **`Stop`** vs **`Advance To Next Preset`**;
  **`Startup Options`: `Manual Start` / `Auto Start` / `Auto Resume`**.
  → **`Advance To Next Preset` + `Auto Resume` are the mechanism by which a *chain* sequences
  presets unattended. `Auto Resume` is what makes an interrupted run continue after a reboot.**
- **Contact Mode Options** — `Ramp Up` 5 V/Sec · `Ramp Down` 5 V/Sec · **`Reduce Amplitude < 10 kHz`**
  (all three unchecked in the screenshot).
  → **`Reduce Amplitude < 10 kHz` is a Contact-specific preset behaviour: the generator attenuates
  amplitude below 10 kHz. If a `(C)` shell carries this flag, its low-frequency programs are
  deliberately gentler.** *INFERENCE — the guide does not explain the rationale.*
- **Frequency Limits (Hz)** — separate `Out 1` / `Out 2` `>` and `<` boxes, each with an `Octave`
  dropdown and a `* = Experimental` legend.
  → **Per-output frequency clamps. A shell preset can restrict a program to a band or octave range
  — a real reason two shells with the same program differ.**
- **Output Control** — `Out 1 = 0 Hz` / `Swap Waveform Every 1 Seconds` / radio options:
  `Out 2 = (Out 1)`, `Out 1 fixed at 3100000 Hz`, `Out 2 Follows Program Frequency`,
  `Out 2 Runs Every Second Frequency`; `Secs Between Freq`; `Swap Out 1 And Out 2`.
  → **`Out 2 = (Out 1)` is the software form of a "Dual"/mirrored output: the same signal on both
  channels. This is the only thing in the batch that could correspond to a `(Dual)` corpus
  token — the word "Dual" itself never appears.**

# Highest-value takeaways for the preset recommender

1. **Shell Preset = empty preset = settings only, no programs** (p36, p27, and the p17 URL
   slug). This is the primary structural split in the 48,463-file corpus. A shell is a
   *delivery recipe*; a non-shell factory preset is shell + programs pre-loaded.
2. **Chain = auto-loader**: an ordered run of any number of presets, each with any number of
   programs (p36). `Repeat Chain` reloads and refires the whole chain indefinitely (p37, p28).
3. **Kill vs heal has a hard rule attached**: `Spectrum`/`Carrier` sweeps are **killing** tools;
   **healing works through entrainment and sweeps do not work for it** (p40). Combined with the
   p7 week-cap, no sweep may ever be recommended as a healing program.
4. **Healing mechanism = entrainment toward a higher healthy frequency**; killing mechanism =
   the positive/negative strike alternation of a damped waveform (p35, p36 worked examples:
   600 Hz healthy vs 598 Hz unhealthy; Damped Square = 24 strikes, 12+ and 12−).
5. **Mode ranking by the guide's own words** (p40): Plasma fastest/most powerful → Contact next
   (with a dynamic carrier) → Remote has gained on Contact and wins on convenience. Coil and
   Scalar are named **healing** devices; Laser is named **superficial/local/perfusion**.
6. **Canonical multi-mode day (p40)**: "one plasma or contact session daily, **then switch that
   generator to Remote Mode**" — mirrored on the plasma side by p13's "run non-stop
   **detox/support Programs remotely** during and after plasma sessions."
7. **Every kill must be paired with a detox** (p15), and the guide names the specific program:
   **`RX Herxheimer - DB`**, triggered by Herxheimer reaction (nausea, joint/lower-back pain),
   run inside the Morgellons & Lyme Protocol.
8. **2–3 day trial per targeted program, then rotate** (p40) — a recommendation is a trial, not
   a regimen.
9. **Safety lock**: no preset loads or fires until `Overwrite Generator` / `Allow Generators
   Overwrite` is ticked, then the generator's button is clicked (p37, p30, p32). Also:
   **never hand-edit a Spooky Central/Plasma preset's signal settings — only `Schedule` and
   `Audio Options` are always safe** (p29); duty stays at 50% for plasma (p29, p7); do not
   uncoil the USB cable's metal ring (p25, p7); Spooky Pulse is bounded at **30–130 BPM,
   HRV ≤ 30** (p32).

    hair carries only RNA and needs the root bulb) (p39). Recommendation cadence for Remote
    must respect sample freshness.
11. **Presets carry no dose by themselves; four levers set the dose**: `Dwell Multiplier`,
    `Frequency Multiplier`, `Repeat Each Frequency/Program/Sequence/Chain` (p28, p37). A shell can
    also gate output at **4 Hz, 125 ms on / 125 ms off** and clamp per-output frequency to an
    octave/band (p29) — this is why two shells with an identical program differ.

    **`Apply Inhibit Factor to Harmful MW Substances`** checkbox (p28) with
    **MW Inhibit Factor = √2·10^17** vs **MW to Hz Factor = 2.2523430883E+23** (p32).
    **MW Emulate / MW Remove as shell names are not defined in this batch** — see the audit above

13. **Software decision machinery** (for "which program to run"): search all databases
